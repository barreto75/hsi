# Holy Spirit Institute School Management System — V3

This V3 build focuses on a cleaner, mobile-friendly admin experience and real CRUD workflows.

Admin CRUD pages:
- Students: Create, Read, Update, Deactivate
- Teachers: Create, Read, Update, Deactivate
- Parents: Create, Read, Update, Deactivate
- Classes: Create, Read, Update, Deactivate
- Divisions: Create, Read, Update, Delete
- Subjects: Create, Read, Update, Deactivate
- Events: Create, Read, Update, Delete
- Notices: Create, Read, Update, Delete

UI improvements:
- Responsive sidebar
- Searchable tables
- Clear status badges
- Modal forms
- Edit/delete/deactivate actions
- Success/error feedback
- Better mobile layout
- Shared UI components and CSRF protection
